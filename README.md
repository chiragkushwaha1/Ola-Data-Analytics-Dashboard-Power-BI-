# Ola-Data-Analytics-Dashboard-Power-BI-
# 📌 Project Overview

This project focuses on analyzing Ola ride booking data using Power BI to generate meaningful business insights. The dashboard helps understand ride patterns, customer behavior, revenue trends, and operational performance of the ride-hailing service.

# 🎯 Objectives
Analyze overall ride performance (completed, cancelled, and total rides)
Understand revenue trends and peak demand hours
Study customer booking behavior and ride frequency
Evaluate city-wise demand distribution
Track driver performance and efficiency
# 🛠️ Tools & Technologies Used
Power BI – Data visualization and dashboard creation
SQL – Data extraction, cleaning, and querying
Excel – Initial data preprocessing and formatting
# 📊 Dashboard Features
Total rides & booking status analysis
Revenue and earnings insights
Peak time and demand analysis
City-wise ride distribution
Driver performance metrics
Interactive filters and slicers for dynamic insights
# 📈 Key Insights
Identified peak booking hours with highest demand
Found major contributing cities for revenue generation
Analyzed cancellation trends and ride completion rates
Helped understand customer behavior patterns for better decision-making
# 🚀 Outcome

This project improved my skills in data analysis, dashboard designing, and business storytelling using real-world datasets. It demonstrates how data can be used to optimize operations in a ride-hailing business.
